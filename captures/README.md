# TourBox Lite 原始设备采集归档

本地复测入口是 [设备数据采集说明](../tourbox_lite_data_collection.md)及`../tools/tourbox_probe.py`，脚本默认向本项目`captures/`写入新会话文件；不要覆盖上述原始文件。脚本复制内容不变，其协议模板来源许可证位于`../third_party/tuxbox-LICENSE.txt`。

这是历史直接USB证据，不是当前固件状态快照。原始报告/profile中的“BLE未验证”“非零配置未测试”等字段描述采集当时的范围。2026-11-20固件1.0.2已新增B5非零参数适配、实际USB/BLE输入和自动重连验证，见 [设计文档](../tourbox_lite_esp32_s3.md)及 [固件验证记录](../docs/validation.md)。当前 [设备摘要](../docs/lite-observed-profile.json)通过相对路径关联本目录证据。

JSONL记录的是macOS串口读取分块和主机时间戳，不能用作USB包边界或总线精确时序。配置声明100mA不是实测电流；同次上电重开不等于非易失持久化；26字节解锁样本不能据此伪造认证回复。
